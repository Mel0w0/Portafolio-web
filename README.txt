Proyecto Portafolio Web 

Este es mi portafolio personal, diseñado para mostrar mis habilidades, proyectos y experiencias.
Esta desarrollado utilizando tecnologías como HTML, CSS y JavaScript.



Descripción

Este proyecto es una página web diseñada para mostrar de manera interactiva mi portafolio profesional,.
Incluye secciones sobre mí, habilidades, proyectos, educación y contacto. Está optimizada para ser
responsiva y accesible en múltiples dispositivos.


Características 

•Diseño moderno y responsivo.
•Listado de proyectos con acceso a demos y repositorios.
•Formulario de contacto.
•Compatible con navegadores modernos.


Tecnologías

• Front-end:HTML,CSS y Javascript
• Herramientas de desarrollo: Visual Studio Code
• Deploy: GitHub pages
